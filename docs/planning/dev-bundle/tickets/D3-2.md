## 实现

### 1. RunState 改造（src/sim.rs）

```rust
use std::collections::HashMap;

pub struct RunState {
    pub started: Instant,
    pub ready: bool,
    pub mcu: String,
    pub freq: u32,
    pub voltage_mv: u32,
    // ❌ 删 pub d13: LedLevel,
    pub digital_pins: HashMap<u8, LedLevel>,    // ✅ 新增。key = Arduino D 编号 0-13
    // 后续 D4-1 加 analog_pins: HashMap<u8, u16>
    pub last_pin_event_t_us: u64,
    pub prev_pin_event_t_us: u64,
    pub last_event_t_us: u64,
    pub serial_lines: VecDeque<(u64, String)>,
    pub bridge_exited: bool,
    pub bridge_exit_reason: Option<String>,
    pub button_pressed: bool,
}

impl Default for RunState {
    fn default() -> Self {
        let mut digital_pins = HashMap::new();
        for d in 0..=13u8 {
            digital_pins.insert(d, LedLevel::Off);
        }
        RunState {
            // ... 其他字段
            digital_pins,
            // ...
        }
    }
}

impl RunState {
    /// 返回某 Arduino 数字引脚当前电平（Off if 不存在）
    pub fn digital_pin(&self, d: u8) -> LedLevel {
        self.digital_pins.get(&d).copied().unwrap_or(LedLevel::Off)
    }
}
```

### 2. apply_event 改造

`is_d13` 闭包改成更通用的 `pin_to_d: Fn(&str, u32) -> Option<u8>`，
返回 Arduino D 编号（0-13）或 None。

```rust
// arduino_uno 板：(port, bit) → Arduino D 编号
fn arduino_pin_to_d(port: &str, bit: u32) -> Option<u8> {
    match (port, bit) {
        ("D", 0..=7) => Some(bit as u8),       // D0-D7
        ("B", 0..=5) => Some(bit as u8 + 8),   // D8-D13
        _ => None,
    }
}

// apply_event 里
BridgeEvent::Pin { t_us, port, bit, value } => {
    s.last_event_t_us = t_us;
    s.prev_pin_event_t_us = s.last_pin_event_t_us;
    s.last_pin_event_t_us = t_us;
    if let Some(d) = pin_to_d(&port, bit as u32) {
        s.digital_pins.insert(d, if value != 0 { LedLevel::On } else { LedLevel::Off });
    }
}
```

### 3. render.rs / tui.rs / inspector.rs 跟进

凡是 `state.d13` 的地方，改成 `state.digital_pin(13)`。
TUI 渲染 LED 时根据 wire 推断"这个 LED 接在哪个引脚"，去 RunState 查该引脚状态。

具体逻辑：
- 遍历 `project.wires`
- 对每根 wire `from = board.Dn`，记下 LED 实例 id 对应 D 编号
- 渲染 LED 时去 state 查对应引脚

### 4. STM32 板 pin_to_d 怎么办

STM32 用 `PA0..PC15` 命名，没有"D 编号"概念。`stm32f405::pin_to_d` 暂时返回 None
（即 STM32 上的所有 pin 事件不更新 `digital_pins`）。

或者更优雅：把 `pin_to_d` 改成 board-agnostic 的字符串 key，例如：

```rust
pub digital_pins: HashMap<String, LedLevel>,  // key 例如 "D13" 或 "PA13"
```

**选项 A**（u8 key + Arduino 风格）：简单，但 STM32 上的 LED 不能用统一查询。
**选项 B**（String key + 完整引脚名）：更通用，但有点重。

**Phase 1 选 A**（u8 key），STM32 渲染暂用 `last_pin_event_t_us` 单值，详细多 pin
渲染留 Phase 2。这样 D3-2 只优化 Arduino，STM32 不退化。

**src/main.ino**：

```cpp
unsigned long last_d7  = 0;
unsigned long last_d11 = 0;
unsigned long last_d13 = 0;
bool s_d7 = false, s_d11 = false, s_d13 = false;

void setup() {
    pinMode(7, OUTPUT);
    pinMode(11, OUTPUT);
    pinMode(13, OUTPUT);
}

void loop() {
    unsigned long now = millis();
    if (now - last_d7 >= 500)   { s_d7 = !s_d7;   digitalWrite(7, s_d7);   last_d7 = now; }
    if (now - last_d11 >= 1000) { s_d11 = !s_d11; digitalWrite(11, s_d11); last_d11 = now; }
    if (now - last_d13 >= 200)  { s_d13 = !s_d13; digitalWrite(13, s_d13); last_d13 = now; }
}
```

## 测试

```rust
#[test]
fn run_state_default_has_all_14_digital_pins() {
    let s = RunState::default();
    for d in 0..=13u8 {
        assert_eq!(s.digital_pin(d), LedLevel::Off);
    }
}

#[test]
fn arduino_pin_to_d_mappings() {
    assert_eq!(arduino_pin_to_d("D", 0), Some(0));
    assert_eq!(arduino_pin_to_d("D", 7), Some(7));
    assert_eq!(arduino_pin_to_d("B", 0), Some(8));
    assert_eq!(arduino_pin_to_d("B", 5), Some(13));
    assert_eq!(arduino_pin_to_d("C", 0), None);
    assert_eq!(arduino_pin_to_d("D", 8), None);
}

#[test]
fn apply_event_updates_correct_pin() {
    let state = Arc::new(Mutex::new(RunState::default()));
    let ev: BridgeEvent = serde_json::from_str(
        r#"{"event":"pin","t_us":1,"port":"D","bit":7,"value":1}"#
    ).unwrap();
    apply_event(&state, ev, &arduino_pin_to_d);
    assert_eq!(state.lock().unwrap().digital_pin(7), LedLevel::On);
    assert_eq!(state.lock().unwrap().digital_pin(13), LedLevel::Off);
}
```
