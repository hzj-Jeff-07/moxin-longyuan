# D9-4 · 视频字幕 + 英文字幕

预计工时：1 小时
模块：视频后期

---

## 任务

给 D9-3 的视频加：
- 中文字幕（硬字幕烧入或 srt 都可）
- 英文字幕（YouTube 上传用，srt 文件）

英文字幕是给投资人国际化做的。MoXin 商业计划里有"出海"愿景，这一步把它落到看得见的产物上。

## 验收

```
docs/demo/
├── video-zh.mp4       # 中文字幕版（B 站 / 视频号）
├── video-en.mp4       # 英文字幕版（YouTube）
├── subtitles-zh.srt
└── subtitles-en.srt
```

## 字幕原则

- 每行 ≤ 20 字（中文）/ 8 词（英文）
- 一屏只显示 1-2 行
- 显示时长 ≥ 2 秒（除非很短的过场词）
- 不要逐字翻译，**翻译意思**

## 工具

- 中文：自己写 srt 或用 WhisperX 自动生成后人工修
- 英文：用 DeepL / Claude 翻译中文 srt
- 烧入视频：FFmpeg / DaVinci Resolve

## srt 模板示例

```
1
00:00:00,000 --> 00:00:03,000
AI 能写代码、能 review

2
00:00:03,000 --> 00:00:06,000
但碰到硬件问题就抓瞎

3
00:00:06,000 --> 00:00:09,000
因为硬件不会跟 AI 对话——直到 MoXin
```

对应英文：

```
1
00:00:00,000 --> 00:00:03,000
AI can write and review code

2
00:00:03,000 --> 00:00:06,000
But hardware issues stop it cold

3
00:00:06,000 --> 00:00:09,000
Hardware can't talk to AI — until MoXin
```

## 约束

- ❌ 不要机器翻译（DeepL / Claude 起草，人工 review）
- ❌ 不要在英文版加无关 hook（保持与中文同样节奏）
- ✅ 把字幕文件 commit 进 repo，便于以后追溯
