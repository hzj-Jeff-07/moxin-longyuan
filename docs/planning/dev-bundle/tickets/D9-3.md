## 任务

根据 D9-2 的 session-log，正式录一段 demo 视频。标题候选：

- "Claude Code 用 MoXin 自动调试嵌入式代码"
- "AI 第一次看懂硬件"

发 B 站 + 视频号 + Twitter / YouTube。

## 验收

- 视频文件 3-5 分钟 mp4 / mov，1080p
- 上传 B 站获得链接（视频号 / YouTube 也上传，链接备齐）
- README 顶部插入视频缩略图 + 链接

## 录制脚本

```
[0:00 - 0:15] 钩子
画面：Wokwi / 真硬件接线乱糟糟 vs MoXin 终端干净 JSON 流
旁白："AI 工具能写代码，能 review，但碰到硬件问题就抓瞎。
       因为硬件不会通过 stdout 跟 AI 对话——直到 MoXin。"

[0:15 - 0:45] 问题展示
画面：Cursor 里打开 buggy-blink，用户输入 "this blink isn't working"
AI 开始读代码，找不出明显问题

[0:45 - 2:30] AI 用 MoXin 工具定位
画面：AI 跑 moxin run --output json
      AI 注意到时间戳间隔
      AI 跑 moxin status / moxin assert
      AI 锁定 bug：delay(1) 应该是 delay(1000)
      AI 改代码
      AI 重跑验证
字幕："AI 通过 MoXin 实时 JSON 流定位硬件 bug"

[2:30 - 3:00] 收尾
画面：blink 现在正确工作（TUI 视图）
旁白："MoXin 让每一段嵌入式代码都能被 AI 验证。"
画面：MoXin logo + GitHub 链接 + 安装命令一行
```

## 制作要求

| 项 | 要求 |
|---|---|
| 分辨率 | 1080p 起，建议 1440p（B 站会自动转码） |
| 帧率 | 30fps 够用，60fps 更好 |
| 字幕 | 中文必须，英文同步（D9-4 加） |
| 配乐 | 可选，**音量必须低于人声 20dB**（融资视频不要 BGM 抢戏） |
| 旁白 | 自己读 or AI 合成均可（推荐 ElevenLabs / 系统 TTS） |
| 录制工具 | macOS QuickTime / Linux OBS / Windows 录屏 |
| 剪辑 | DaVinci Resolve（免费）/ CapCut（更简单） |

## 不要做的

- ❌ 不要花哨转场（投资人 PPT 嵌入要求简洁）
- ❌ 不要超过 5 分钟（注意力曲线）
- ❌ 不要演示太多 feature（**只演 AI + JSON + assert 这一条主线**）
- ❌ 不要插入"招聘"或别的无关信息
