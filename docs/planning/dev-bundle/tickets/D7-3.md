# D7-3 · 实现 `moxin assert "..."` CLI 入口

预计工时：2 小时
模块：main / cmd_assert

## 任务

接 D7-2 的 parser + matcher 到 CLI，做成 `moxin assert "<expr>"` 命令。

## 验收

```bash
moxin run &
sleep 1

moxin assert "pin D13 HIGH within 2s"
echo $?    # 0 if pass, 1 if fail

moxin assert "serial contains \"ready\" within 1s"
echo $?

moxin assert "pin D7 HIGH within 100ms"
echo $?    # 1 if D7 不在 HIGH

# JSON 输出
moxin assert --output json "pin D13 HIGH within 1s"
# {"result":"PASS","elapsed_ms":...}
# or
# {"result":"FAIL","reason":"...","elapsed_ms":...}
```

## 实现

### 1. main.rs 子命令

```rust
#[derive(Subcommand)]
enum Cmd {

        expression: String,

        output: String,
        #[arg(long)]

```

### 2. src/cmd_assert.rs

```rust
pub fn cmd_assert(args: AssertArgs) -> Result<()> {
    let expr = assert::parse(&args.expression)?;
    let mut stream = FilePollSnapshotStream::new();   // 50ms 轮询 snapshot 文件
    let result = assert::evaluate(&expr, &mut stream);

    match args.output.as_str() {
        "json" => {
            let j = serde_json::to_string(&result)?;
            println!("{}", j);
        }
        _ => {
            match &result {
                AssertResult::Pass { .. } => println!("PASS"),
                AssertResult::Fail { reason, .. } => eprintln!("FAIL: {}", reason),
            }
        }
    }

    if matches!(result, AssertResult::Fail { .. }) {
        std::process::exit(1);
    }
    Ok(())
}
```

### 3. FilePollSnapshotStream

实现 D7-2 的 SnapshotStream trait：

```rust
struct FilePollSnapshotStream {
    deadline: Instant,
}

impl SnapshotStream for FilePollSnapshotStream {
    fn next(&mut self) -> Option<RunStateSnapshot> {
        if Instant::now() > self.deadline {
            return None;
        }
        std::thread::sleep(Duration::from_millis(50));
        let files = sim::find_status_files().ok()?;
        let latest = files.last()?;
        let f = File::open(latest).ok()?;
        serde_json::from_reader(f).ok()
    }
}
```
