# D1-5 · examples/stm32-blink 文件结构与 cmd_new 生成保持一致

预计工时：30 分钟
模块：examples

---

## 任务

`examples/stm32-blink/moxin.toml` 现在写 `src = "main.c"`，`main.c` 在 example 根目录。
但 `cmd_new --board=stm32` 生成的项目结构是 `src = "src/main.c"`，主文件在 `src/` 子目录。
同一仓库两套约定，照 example 学的用户照 cmd_new 创建会懵。

策略：example 改用与 cmd_new 一致的 `src/main.c` 结构。

## 验收命令

```bash
cd moxin-longyuan
ls examples/stm32-blink/        # 应有 src/、Makefile、moxin.toml、support/
ls examples/stm32-blink/src/    # 应有 main.c
cat examples/stm32-blink/moxin.toml | grep 'src = "src/main.c"'

cd examples/stm32-blink
moxin run                       # 跑通 STM32 blink

# 与 cmd_new 对照
cd /tmp && moxin new compare --board=stm32
diff -r /tmp/compare/src examples/stm32-blink/src   # 结构一致（内容可不同）
```

## 涉及的文件

### 文件移动

```
examples/stm32-blink/
├── main.c            →  src/main.c
├── Makefile          ← 改 SRCS 路径
├── moxin.toml        ← 改 src 字段
├── support/
│   ├── startup.s
│   └── linker.ld
└── README.md         ← 若有，更新路径说明
```

### moxin.toml 改动

```toml
# before
[project]
name = "stm32-blink"
board = "stm32"
src = "main.c"          # ❌

# after
[project]
name = "stm32-blink"
board = "stm32"
src = "src/main.c"      # ✅
```

### Makefile 改动

```makefile
# before
SRCS = support/startup.s main.c

# after
SRCS = support/startup.s src/main.c
```

注意如果 Makefile 还引用 main.c 的别处（OBJS 等），同步改。

## 约束

- ❌ 不要改 main.c 的内容
- ❌ 不要改 support/startup.s 或 linker.ld
- ❌ 不要影响 examples/led-control（那是 Arduino 例子，结构不同）
- ✅ 用 `git mv main.c src/main.c` 保留文件历史

## 操作步骤

```bash
cd examples/stm32-blink
mkdir -p src
git mv main.c src/main.c
# 改 moxin.toml 和 Makefile
git add .
git commit -m "..."
```
