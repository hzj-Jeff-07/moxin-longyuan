# D6-2 · 实现运行时状态快照写入 ~/.cache/moxin/sim-<pid>.json

预计工时：2.5 小时
模块：sim

---

## 任务

按 D6-1 RFC 决定的 file polling 方案，让正在跑的 sim 每 50ms 把最新 RunState
快照写入 `~/.cache/moxin/sim-<pid>.json`，进程退出时删除文件。

为 D6-3 `moxin status` 提供数据源。

## 验收

```bash
cd /tmp && moxin new query-test --board=uno && cd query-test
moxin run &
PID=$!
sleep 1
cat ~/.cache/moxin/sim-$PID.json | jq .   # 输出 JSON，含 mcu / freq / digital_pins / ...
sleep 1
ls ~/.cache/moxin/sim-*.json              # 文件存在
kill $PID
sleep 1
ls ~/.cache/moxin/sim-*.json              # 文件被删
```

## 实现

### 1. 快照 schema

```rust
#[derive(Serialize)]
struct RunStateSnapshot {
    pid: u32,
    mcu: String,
    freq: u32,
    voltage_mv: u32,
    uptime_us: u64,
    digital_pins: HashMap<String, String>,    // "D13": "HIGH" / "LOW"
    analog_pins: HashMap<String, u16>,
    serial_lines: Vec<(u64, String)>,
    button_pressed: bool,
    ready: bool,
    bridge_exited: bool,
}
```

### 2. 快照线程

在 spawn_sim 时再起一个线程，每 50ms：
1. lock 一次 state
2. clone 出 snapshot
3. unlock
4. atomic write：写到 `sim-<pid>.json.tmp` 然后 rename 到 `sim-<pid>.json`

`atomicwrites` crate 太重，手写 rename 即可。

### 3. 文件清理

`Drop for RunningSim` 里清快照文件。配合 D2-3 的 stop() 同步。

### 4. find_status_file()

`~/.cache/moxin/` 下找最新的 sim-*.json，给 D6-3 用：

```rust
pub fn find_status_files() -> Result<Vec<PathBuf>> {
    let dir = cache_dir()?;
    let mut files: Vec<_> = std::fs::read_dir(dir)?
        .filter_map(Result::ok)
        .map(|e| e.path())
        .filter(|p| {
            p.file_name()
                .and_then(|n| n.to_str())
                .map(|n| n.starts_with("sim-") && n.ends_with(".json"))
                .unwrap_or(false)
        })
        .collect();
    files.sort_by_key(|p| p.metadata().and_then(|m| m.modified()).ok());
    Ok(files)
}
```
