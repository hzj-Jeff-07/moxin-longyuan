# D2-1 · TUI 模式切换：Ctrl-S 进 serial 模式，Esc 回命令模式

预计工时：2 小时
模块：tui

---

## 任务

当前 `src/tui.rs` 大约第 460 行：

```rust
if input.buffer.is_empty() {
    if let Some(sim) = shell.running.as_mut() {
        if let Some(stdin) = sim.stdin.as_mut() {
            let _ = stdin.write_all(&[c as u8]);    // 发到 bridge
        }
    }
}
input.insert_char(c);    // ← 同时也插进 buffer
```

用户输 `r` 想发 serial RX 给 firmware，结果 `r` 既被发给 firmware **也**被压进命令
buffer，接下来打 `un` 就 dispatch 了 `run` 命令，混乱。

策略：把"打命令"和"发 serial"做成显式模式。状态条底部显示当前模式。

## 验收命令

```bash
cd moxin-longyuan
cargo test                # 全绿
cargo build --release
cd /tmp && moxin new test-mode --board=uno && cd test-mode
moxin run                 # 进 TUI
```

在 TUI 里手动验证：
- 默认是命令模式，状态条显示 `[MODE: COMMAND]`
- 打字打 `run` 回车 → 启 sim
- 按 `Ctrl-S` → 状态条变 `[MODE: SERIAL]`，输入框 prompt 从 `moxin >` 变成 `serial >`
- 打字 `hello` 直接发给 firmware stdin，不进入命令 buffer
- 按 `Esc` → 回 `[MODE: COMMAND]`，buffer 清空
- 在 SERIAL 模式下按 `Esc` 不退出 TUI（只是回 COMMAND 模式）；在 COMMAND 模式按 `q` 才退出
- TUI 在 sim **未运行**时切到 SERIAL 模式 → 显示提示 "no sim running, return to command mode"，自动回 COMMAND

## 实现要点

### 1. 加 InputMode enum

在 src/tui.rs 顶部：

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum InputMode {
    Command,
    Serial,
}

impl InputMode {
    fn prompt(&self) -> &'static str {
        match self {
            InputMode::Command => "moxin > ",
            InputMode::Serial => "serial > ",
        }
    }
    fn label(&self) -> &'static str {
        match self {
            InputMode::Command => "[MODE: COMMAND]",
            InputMode::Serial => "[MODE: SERIAL]",
        }
    }
}
```

### 2. 状态字段

`InputState` 加 `mode: InputMode`，默认 `Command`。

### 3. 按键路由

主键盘事件 match 改成两层：先 match mode，再 match key。

```rust
match input.mode {
    InputMode::Command => match key.code {
        KeyCode::Char('s') if key.modifiers.contains(KeyModifiers::CONTROL) => {
            if shell.running.is_some() {
                input.mode = InputMode::Serial;
                input.buffer.clear();
                input.cursor = 0;
            } else {
                // 显示提示，不切模式
                shell.last_message = Some("no sim running — start one first".into());
            }
        }
        KeyCode::Char('q') => break,
        KeyCode::Enter => { /* dispatch command */ }
        KeyCode::Char(c) => input.insert_char(c),
        // ...
    },
    InputMode::Serial => match key.code {
        KeyCode::Esc => {
            input.mode = InputMode::Command;
            input.buffer.clear();
            input.cursor = 0;
        }
        KeyCode::Char(c) => {
            // 立即发给 bridge stdin，不进 buffer
            if let Some(sim) = shell.running.as_mut() {
                if let Some(stdin) = sim.stdin.as_mut() {
                    let _ = stdin.write_all(&[c as u8]);
                }
            }
            // 仍然在 input.buffer 显示，便于用户看到自己打了什么
            input.insert_char(c);
        }
        KeyCode::Enter => {
            if let Some(sim) = shell.running.as_mut() {
                if let Some(stdin) = sim.stdin.as_mut() {
                    let _ = stdin.write_all(b"\n");
                }
            }
            input.buffer.clear();
            input.cursor = 0;
        }
        KeyCode::Backspace => { /* 本地删 + 不发 backspace 给 firmware（一般 firmware 自己处理） */ }
    }
}
```

### 4. 状态条

在 footer 区域加 `input.mode.label()`。

### 5. 删旧逻辑

把原先 `if input.buffer.is_empty()` 那段双发逻辑**完全删掉**，以模式切换替代。
