## 内容要点

**问题**：另一个进程（CLI / AI tool）查询正在跑的 sim 的 RunState。

**方案 A：Unix socket**
- macOS / Linux 原生支持，Windows 10 后也有
- 优点：双向、低延迟、能多客户端
- 缺点：Windows 实现细节有差异

**方案 B：Named pipe**
- Windows 原生，类 Unix 上 mkfifo
- 优点：跨平台 API 区别小
- 缺点：单工，多客户端要绕

**方案 C：File polling**
- 主 sim 把 RunState dump 到 ~/.cache/moxin/<pid>.json，查询方读文件
- 优点：实现最简单，0 依赖
- 缺点：有 1-N ms 延迟，原子性要小心（写时锁文件 or tmp file rename）

**推荐**：方案 C（文件）做 Phase 1。理由：
- 实现简单，10 天工期紧
- 延迟 < 100ms 对 assert 命令足够（默认 timeout 秒级）
- 跨平台简单（一个 std::fs::write 搞定）
- Phase 2 性能瓶颈时再升级到 socket

**实现要点**（给 D6-2 用）：
- sim 起来时记录 pid，写 ~/.cache/moxin/sim-<pid>.json，进程退出时删
- 每 50ms 写一次最新 RunState 快照（debounce）
- 查询方扫 ~/.cache/moxin/sim-*.json，多个文件就取最近 mtime 的
- 文件格式：与 `moxin run --output json` 的最终状态一致
