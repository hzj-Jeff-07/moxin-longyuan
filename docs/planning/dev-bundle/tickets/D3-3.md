### 4. 频率检测算法

蜂鸣器接的引脚每次电平翻转，记录时间。计算最近 N 次翻转的平均周期 → 转换为 Hz。

```rust
impl BuzzerState {
    fn record_toggle(&mut self, t_us: u64) {
        if self.last_toggle_t_us == 0 {
            self.last_toggle_t_us = t_us;
            return;
        }
        let half_period_us = t_us.saturating_sub(self.last_toggle_t_us);
        self.last_toggle_t_us = t_us;
        if half_period_us == 0 { return; }
        // 一个完整周期 = 2 × 半周期；Hz = 1_000_000 / period_us
        let full_period_us = half_period_us * 2;
        self.frequency_hz = (1_000_000 / full_period_us) as u32;
        self.active = self.frequency_hz > 20;   // 低于 20Hz 视为静默
    }
}
```

判断"激活"用 timeout：如果 100ms 没翻转，置 active = false。这个检查放在 TUI 渲染
循环或定期 tick 里。

### 5. apply_event 中触发频率检测

需要在 Pin 事件触发时，看哪个 buzzer 接在该引脚，调它的 record_toggle。

具体怎么把 (D 编号 → buzzer 实例)：

- shell.rs 在加载 project / 加 wire 后，建一个 `pin_to_buzzer: HashMap<u8, String>` 索引
- 传给 spawn_sim → reader_loop 闭包能访问
- apply_event 里：if let Some(buzzer_id) = pin_to_buzzer.get(&d) { buzzers[buzzer_id].record_toggle(t_us) }

具体注入路径看现有 `is_d13` 闭包是怎么传的，按同样方式传 `pin_to_buzzer`。

### 6. render.rs / TUI 蜂鸣器渲染

```
[Buzzer:buzz1 ─]              ← 静默
[Buzzer:buzz1 ♪ 440Hz]        ← 发声
```

用 `state.buzzers.get(id)` 取状态，按 active / frequency_hz 决定文字。

## 单元测试

```rust
#[test]
fn buzzer_records_toggle_at_440hz() {
    let mut b = BuzzerState::default();
    // 440Hz = 周期 ~2272us = 半周期 ~1136us
    b.record_toggle(0);
    b.record_toggle(1136);
    assert!((b.frequency_hz as i32 - 440).abs() < 10);
    assert!(b.active);
}

#[test]
fn buzzer_silent_when_no_toggles() {
    let b = BuzzerState::default();
    assert!(!b.active);
    assert_eq!(b.frequency_hz, 0);
}
```
