# D8-1 · `moxin run --output json` 模式

预计工时：2 小时
模块：main / shell

---

## 任务

新加 `moxin run --output json` 选项，让 sim 的 JSON Lines 事件流**直接写 stdout**，
不开 TUI。给 AI 工具消费用。

## 验收

```bash
cd /tmp && moxin new json-test --board=uno && cd json-test
moxin run --output json | head -20
# 输出：
# {"event":"ready","mcu":"atmega328p","freq":16000000}
# {"event":"pin","t_us":12345,"port":"B","bit":5,"value":1}
# {"event":"serial","t_us":12346,"line":"hello"}
# ...
```

stdout 必须是合法 JSON Lines（每行一个 JSON 对象，能被 `jq -c` 消费）。
stderr 可以有 warning / status，不混入 stdout。

## 实现

### 1. main.rs run 子命令

```rust
Run {
    #[arg(long, default_value = "tui")]
    output: String,    // "tui" | "json"
}
```

### 2. shell.rs / sim.rs

`cmd_run` 里：

```rust
if output == "json" {
    // 直接 spawn bridge，stdout 不接 reader_loop，直接 inherit 给当前进程
    // 然后 wait child 退出
    let child = Command::new(bridge_path)
        .arg(artifact)
        .stdout(Stdio::inherit())   // 关键：bridge stdout 透传给 moxin stdout
        .stderr(Stdio::piped())     // stderr 写日志
        .spawn()?;
    let _ = child.wait();
}
```

Or（更清洁）：保留 reader_loop，但 reader 里把 JSON 行 println!() 出去同时
更新 RunState。这样 Ctrl-C 也能 graceful 退出。

### 3. 处理 Ctrl-C

`ctrlc` crate 或手动 signal handler，捕获 SIGINT，kill bridge 后 graceful exit。

## 约束

- ❌ 不要改 bridge 协议
- ❌ 不要改 BridgeEvent
- ❌ stdout 严格 JSON Lines，不要混入 ANSI / 状态文本
- ❌ 不要影响 default tui 模式（用户不传 --output 时行为不变）
- ✅ 允许加 ctrlc = "3" 依赖（如需 SIGINT 处理）
