# D2-3 · RunningSim::stop 改用 join handle 字段，不再 detach 线程

预计工时：1 小时
模块：sim

---

## 任务

`src/sim.rs` 的 `RunningSim::stop` 起一个 detached 后台线程做 wait + join：

```rust
std::thread::spawn(move || {
    let _ = child.wait();
    if let Some(h) = reader { let _ = h.join(); }
    if let Some(h) = stderr_reader { let _ = h.join(); }
});
```

每次 `run → stop` 周期都泄漏一个线程。短 demo 没事，长会话开几十次会堆。

策略：把 reader / stderr_reader 的 JoinHandle 保留在 RunningSim 字段里，stop 时
同步等它们结束（child wait 已经会让 reader 自然 EOF 退出，毫秒级）。

## 实现

### 1. RunningSim 加字段

```rust
pub struct RunningSim {
    pub child: Option<Child>,
    pub stdin: Option<ChildStdin>,
    pub state: Arc<Mutex<RunState>>,
    pub reader: Option<JoinHandle<()>>,
    pub stderr_reader: Option<JoinHandle<()>>,
    // ...
}
```

`std::thread::JoinHandle` 需要 `use std::thread::JoinHandle;`。

### 2. spawn_sim 设置字段

各 board 的 `spawn_sim`（arduino_uno.rs、stm32f405.rs）里：

```rust
let reader = std::thread::spawn(move || reader_loop(stdout, state_clone, is_d13));
let stderr_reader = std::thread::spawn(move || stderr_reader_loop(stderr, log_path));

Ok(RunningSim {
    child: Some(child),
    stdin: Some(stdin),
    state,
    reader: Some(reader),
    stderr_reader: Some(stderr_reader),
})
```

### 3. stop 同步 join

```rust
impl RunningSim {
    pub fn stop(&mut self) {
        // 1. kill child（如果还在）
        if let Some(mut child) = self.child.take() {
            let _ = child.kill();
            let _ = child.wait();
        }
        // 2. drop stdin（关闭 fd，bridge 收到 EOF 也会自己退出）
        self.stdin = None;
        // 3. join reader 线程（child 死后 stdout EOF，reader 自然返回）
        if let Some(h) = self.reader.take() {
            let _ = h.join();
        }
        if let Some(h) = self.stderr_reader.take() {
            let _ = h.join();
        }
    }
}
```

### 4. Drop impl

为了不在 Drop 时 detach 线程，给 RunningSim 加 Drop：

```rust
impl Drop for RunningSim {
    fn drop(&mut self) {
        self.stop();
    }
}
```

注意 Drop 不能返回错误，stop 内部已经 `let _ = ...` 处理了，OK。

## 约束

- ❌ 不要改 reader_loop / stderr_reader_loop 函数签名
- ❌ 不要改 bridge 协议
- ❌ 不要新增依赖
- ✅ 允许给 RunningSim 加 Drop impl
- ✅ 各 board 的 spawn_sim 内部小调整可以接受

## Commit message

```
sim(D2-3): RunningSim 保留 reader 线程 JoinHandle，stop 同步 join

之前 stop() 起一个 detached 线程做 wait + join，每次 run/stop 循环
泄漏一个线程。长会话累积下来 macOS 上能看到 50+ 残留线程。

- RunningSim 加 reader / stderr_reader: Option<JoinHandle<()>>
- arduino_uno / stm32f405 的 spawn_sim 设置这两个字段
- stop() 改为同步：kill child → wait → join readers
- 加 Drop impl 防止意外 drop 时仍然泄漏

ref: docs/sprint-plan.md D2-3
```
