模块：main / cmd_status

## 任务

新 CLI 子命令 `moxin status` 查询正在跑的 sim 状态。

子命令形式：
- `moxin status --all` → 输出完整快照 JSON
- `moxin status --pin D13` → 输出 `{"pin":"D13","value":"HIGH","at_us":12345}`
- `moxin status --serial-tail` → 输出最近 N 行串口
- `moxin status --pretty` → 人类友好的多行输出（默认 JSON）

## 验收

```bash
moxin run &
sleep 1
moxin status --all | jq .
moxin status --pin D13
moxin status --serial-tail
echo $?    # 0
```

无 sim 跑：
```bash
moxin status --all
# stderr: "no running sim found"
# exit code: 1
```

### 2. 新模块 src/cmd_status.rs

```rust
pub fn cmd_status(args: StatusArgs) -> Result<()> {
    let files = sim::find_status_files()?;
    let latest = files.last().ok_or_else(|| anyhow!("no running sim found"))?;
    let snapshot: RunStateSnapshot = serde_json::from_reader(File::open(latest)?)?;

    if let Some(pin) = args.pin {
        let value = snapshot.digital_pins.get(&pin)
            .ok_or_else(|| anyhow!("pin {} not found in snapshot", pin))?;
        println!("{}", serde_json::json!({
            "pin": pin,
            "value": value,
            "at_us": snapshot.uptime_us,
        }));
    } else if args.serial_tail {
        for (t, line) in snapshot.serial_lines.iter().rev().take(args.tail_n) {
            println!("[{}] {}", t, line);
        }
    } else if args.all {
        if args.pretty {
            // 多行人类友好输出
        } else {
            println!("{}", serde_json::to_string_pretty(&snapshot)?);
        }
    }
    Ok(())
}
```
