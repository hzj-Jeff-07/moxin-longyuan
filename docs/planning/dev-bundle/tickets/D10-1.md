## 验收

```markdown
# MoXin

> AI 第一次看懂硬件 / The first hardware simulator built for AI

[demo 视频缩略图]    ← D9-3 视频链接

MoXin 是一个 CLI 嵌入式仿真器，让 Arduino / STM32 等开发板能在终端里跑，
所有运行状态以 JSON Lines 输出，AI 工具（Cursor / Claude Code）能直接消费。

## ⚡ 30 秒上手

\`\`\`bash
cargo install moxin
moxin new demo --board=uno && cd demo
moxin run
\`\`\`

[1 张 TUI 截图 gif]

## ✨ 核心特性

- 🤖 **AI 友好**：`moxin run --output json` / `moxin status` / `moxin assert` 三件套
- 🔌 **多板支持**：Arduino Uno + STM32（Phase 2 加 ESP32 / RPi Pico / 国产芯片）
- 🧰 **9 种元件**：LED / 按钮 / 数码管 / 蜂鸣器 / 电位器 / 电阻 / 面包板 / 杜邦线 / Arduino Uno
- 💻 **跨平台**：macOS / Linux / Windows
- 🪶 **轻量**：单二进制 < 10MB，无 GUI 依赖
```
