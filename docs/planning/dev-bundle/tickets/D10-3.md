## 内容

### tech-highlights.md

```markdown
# MoXin 技术亮点 · 财经路演用

## 一句话价值
**唯一一个为 AI 工具设计的嵌入式仿真器。**

## 三个差异化卖点

1. **JSON 而非 GUI**
   - Wokwi / Tinkercad 都是图形界面，AI 看不懂屏幕像素
   - MoXin 输出结构化 JSON 流，AI 直接消费
   - 实证：Claude Code 通过 MoXin 输出在 60 秒内自动定位嵌入式 bug

2. **CLI 而非 IDE 插件**
   - 不绑定特定 IDE，AI 工具能调 shell 命令就能用
   - 跨 Cursor / Claude Code / Aider / 自研 agent

3. **本地而非云**
   - Wokwi 必须联网，免费版限算力
   - MoXin 本地跑，无限算力，无数据上云顾虑

## 技术栈选型理由

| 技术 | 为什么选 | 竞品差异 |
|---|---|---|
| Rust | 内存安全 + 高性能 + 单文件分发 | Wokwi 用 Python 桌面 |
| ratatui TUI | 终端原生 + AI 工具能消费截图 | 竞品都是浏览器 |
| simavr / QEMU | 工业级仿真器（同 Wokwi 底层） | 同 |
| JSON Lines | AI 友好 + 流式 + 易解析 | 竞品多用专有协议 |

## 路线图

| 阶段 | 产出 | 时间 |
|---|---|---|
| Phase 1 | Arduino Uno + STM32，9 元件，AI 三件套 | ✓ 完成（10 天） |
| Phase 2 | 跨平台 CI + 扩展元件 + ESP32/Pico | 1 个月 |
| Phase 3 | 国产芯片 + MCP Server + GUI（前端部独立做） | 3 个月 |
| Phase 4 | 教育市场分发，与 AI 编程工具深度合作 | 6 个月 |
```

```markdown
# 关键数字 · 财经路演

## 工程指标
- **代码量**：~4500 行 Rust + ~250 行 C
- **测试覆盖**：~60 单测 + 4 集成测试
- **二进制大小**：< 10 MB（vs Wokwi 桌面端 ~200 MB）
- **冷启动时间**：< 1 秒（Arduino 后端）
- **JSON 事件延迟**：< 5 ms（sim 到 stdout）
- **开发周期**：10 天单人开发完成 Phase 1

## 行业对比
- Wokwi 用户：~50 万（公开数据）
- Tinkercad 教学场景：百万级
- Cursor / Claude Code 月活：百万级
- **可寻址市场**：所有用 AI 写嵌入式代码的开发者 + 教育市场

## 成本结构
- 仿真后端零 license（simavr LGPL / QEMU GPL，独立进程隔离）
- 无云依赖，零运维成本
- 单二进制分发，零部署成本
```
