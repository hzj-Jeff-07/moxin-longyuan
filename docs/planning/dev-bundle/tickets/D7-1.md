# D7-1 · 设计 assert DSL 语法

预计工时：1 小时
模块：docs

---

## 任务

写 `docs/design/assert-dsl.md`，定义 `moxin assert "..."` 接受的语法。
覆盖 Phase 1 必需的 4 种断言。

## 验收

文档至少覆盖：

```
# 数字引脚
pin D13 HIGH within 2s
pin A0 between 500 1000 within 5s

# 串口
serial contains "ready" within 3s
serial matches /error: \w+/ within 1s     # 可选：正则

# 元件
led led1 on within 2s
buzzer buzz1 frequency 440 within 5s

# 多个条件用 and / or（可选 Phase 2）
```

每种语法给：
- ABNF grammar
- 3-5 个例子
- 错误情况下的输出 schema

## 内容要点

### Grammar

```
assert    = subject SP predicate SP "within" SP duration
subject   = "pin" SP pin_name
          | "serial"
          | "led" SP component_id
          | "buzzer" SP component_id
predicate = "HIGH" | "LOW"
          | "between" SP NUM SP NUM
          | "contains" SP STRING
          | "on" | "off"
          | "frequency" SP NUM
duration  = NUM ("s" | "ms")
pin_name  = "D" DIGIT [DIGIT] | "A" DIGIT | "PA" DIGIT [DIGIT]
```

### 例子

```
$ moxin assert "pin D13 HIGH within 2s"
PASS                                     # exit 0
# stdout 空 / 加 -v 输出更多

$ moxin assert "serial contains \"ready\" within 1s"
FAIL: serial did not contain "ready" within 1s
expected: serial contains "ready"
actual:   no matching line in 1.0s
exit code: 1
```

### 错误输出 JSON 模式

```bash
$ moxin assert --output json "pin D13 HIGH within 1s"
{
  "result": "FAIL",
  "expression": "pin D13 HIGH within 1s",
  "expected": {"subject":"pin D13","predicate":"HIGH"},
  "actual": {"value":"LOW","at_us":1234567},
  "timeout_ms": 1000,
  "elapsed_ms": 1001
}
```
