# D4-1 · 6 个模拟引脚 ADC 仿真

预计工时：3 小时
模块：bridge / sim

---

## 任务

让 ATmega328P 的 6 个 ADC 通道（A0-A5）能被仿真，firmware 调 `analogRead(0)`
返回的值由 moxin 控制。同时 bridge 上报 `{"event":"adc","pin":"A0","value":...}`
事件。

为电位器（D5-1）做铺垫——电位器调值要走 ADC 通路。

## 验收命令

```bash
cd moxin-longyuan
make -C bridge
cargo test                   # 全绿
cargo build --release

cd /tmp && moxin new adc-test --board=uno && cd adc-test
cat > src/main.ino <<'EOF'
void setup() { Serial.begin(9600); }
void loop() {
    int v = analogRead(A0);
    Serial.println(v);
    delay(100);
}
EOF
moxin run                    # TUI 串口区域显示数字
# 在 TUI 命令模式输：set-adc A0 512  → firmware 串口读到 512 左右
```

## 实现要点

### 1. simavr ADC API

simavr 用 IRQ 注入 ADC 值：

```c
// bridge/moxin-simavr-bridge.c
#include <simavr/sim/avr/sim_adc.h>

avr_irq_register_notify(
    avr_io_getirq(avr, AVR_IOCTL_ADC_GETIRQ, ADC_IRQ_OUT_TRIGGER),
    adc_trigger_cb, NULL
);

// 初始化时给每个 ADC 通道一个默认值
for (int ch = 0; ch < 6; ch++) {
    avr_raise_irq(
        avr_io_getirq(avr, AVR_IOCTL_ADC_GETIRQ, ADC_IRQ_ADC0 + ch),
        0  // 默认 0V
    );
}
```

### 2. bridge 协议入向命令

从 moxin 主进程通过 stdin 注入 ADC 值：

```
set-adc A0 512\n
```

bridge 解析后：

```c
// bridge stdin reader
char line[256];
while (fgets(line, sizeof(line), stdin)) {
    int ch, val;
    if (sscanf(line, "set-adc A%d %d", &ch, &val) == 2 && ch >= 0 && ch < 6 && val >= 0 && val <= 1023) {
        avr_raise_irq(
            avr_io_getirq(avr, AVR_IOCTL_ADC_GETIRQ, ADC_IRQ_ADC0 + ch),
            val
        );
        printf("{\"event\":\"adc\",\"pin\":\"A%d\",\"value\":%d,\"t_us\":%llu}\n",
               ch, val, get_t_us());
        fflush(stdout);
    }
}
```

注意 bridge 现在已经在 main thread 跑 simavr_run；stdin 读取要在另一线程或用
非阻塞 fd。最简单：起 pthread 跑 stdin reader。

### 3. Rust 端 BridgeEvent 加 Adc

```rust
#[serde(tag = "event")]
enum BridgeEvent {
    // ...
    #[serde(rename = "adc")]
    Adc { t_us: u64, pin: String, value: u16 },
}
```

### 4. RunState 加 analog_pins

```rust
pub struct RunState {
    // ...
    pub analog_pins: HashMap<String, u16>,    // key = "A0".."A5"
}
```

### 5. shell.rs cmd_set_adc

```rust
"set-adc" => {
    let pin = ...;  // "A0".."A5"
    let val: u16 = ...; // 0..=1023
    if let Some(sim) = self.running.as_mut() {
        if let Some(stdin) = sim.stdin.as_mut() {
            let cmd = format!("set-adc {} {}\n", pin, val);
            stdin.write_all(cmd.as_bytes())?;
        }
    }
}
```

## 单元测试

```rust
#[test]
fn bridge_event_adc_deserializes() {
    let json = r#"{"event":"adc","t_us":1234,"pin":"A0","value":512}"#;
    let ev: BridgeEvent = serde_json::from_str(json).unwrap();
    match ev {
        BridgeEvent::Adc { pin, value, .. } => {
            assert_eq!(pin, "A0");
            assert_eq!(value, 512);
        }
        _ => panic!("wrong variant"),
    }
}

#[test]
fn apply_event_adc_updates_state() {
    let state = Arc::new(Mutex::new(RunState::default()));
    let ev: BridgeEvent = serde_json::from_str(
        r#"{"event":"adc","t_us":1,"pin":"A0","value":512}"#
    ).unwrap();
    apply_event(&state, ev, &|_, _| None);
    assert_eq!(state.lock().unwrap().analog_pins.get("A0"), Some(&512));
}
```

## 约束

- ❌ 不要改现有 Pin 事件协议
- ❌ 不要动 STM32 ADC（Phase 2）
- ❌ 不要在 simavr main thread 阻塞读 stdin（用 pthread）
- ❌ 不要给电位器添加专门支持（这是 D5-1 ticket）
- ✅ 允许 bridge C 代码引入 pthread
