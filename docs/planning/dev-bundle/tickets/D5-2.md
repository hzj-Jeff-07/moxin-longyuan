# D5-2 · 被动元件 schema 层（resistor / breadboard / dupont）

预计工时：1.5 小时
模块：project / shell / render

---

## 任务

让 `moxin add resistor r1 ohms=220` / `moxin add breadboard bb1` /
`moxin add dupont w1 color=red` 不报错，并在静态项目渲染（render_project）里
正确显示。

被动元件**不写 runtime 行为**（不在 RunState 里跟踪状态），只让 schema 通过 + 静态渲染。
Phase 2 再做物理仿真（分压、面包板节点连通性）。

## 实现

### 1. project.rs Component 加字段

```rust
pub struct Component {
    pub id: String,
    pub r#type: String,
    pub color: Option<String>,        // LED / dupont 共用
    pub ohms: Option<u32>,            // resistor / potentiometer 共用
    pub enable_sound: Option<bool>,   // buzzer
    pub max_ohms: Option<u32>,        // potentiometer
    pub common: Option<String>,       // seven_segment
    pub body_color: Option<String>,   // breadboard / potentiometer
    pub length_mm: Option<u32>,       // dupont
}
```

(字段数量在膨胀，但 Phase 1 接受这个技术债。)

### 2. shell.rs cmd_add 加 3 个分支

```rust
"resistor" => {
    let comp = Component {
        id: arg.to_string(),
        r#type: "resistor".into(),
        ohms: parse_ohms_kwarg(&kwargs).unwrap_or(220),
        // ...
    };
}
"breadboard" => { /* type = "breadboard"，无必填参数 */ }
"dupont" => { /* type = "dupont"，可选 color */ }
```

并解析 `key=value` 风格的 kwargs。如果当前 shell add 不支持 kwargs，先实现：
正则 `^(\w+)=(.+)$` 解析参数。

### 3. render.rs 静态渲染

```
[Resistor:r1 220Ω]
[Breadboard:bb1 ─]
[Wire:w1 ─── red]
```

具体格式参考现有 LED 渲染。

### 4. 不要做的

- ❌ 不要进 RunState（这些元件没运行时状态）
- ❌ 不要做面包板节点连通性逻辑
- ❌ 不要做电阻分压计算
- ❌ 不要做杜邦线 length_mm 路径计算

## 单元测试

```rust
#[test]
fn shell_add_resistor() {
    let mut shell = test_shell();
    shell.dispatch("add resistor r1 ohms=330").unwrap();
    assert_eq!(shell.project.components.len(), 1);
    assert_eq!(shell.project.components[0].ohms, Some(330));
}

#[test]
fn shell_add_resistor_default_ohms() {
    let mut shell = test_shell();
    shell.dispatch("add resistor r1").unwrap();
    assert_eq!(shell.project.components[0].ohms, Some(220));  // 默认值
}

#[test]
fn shell_add_breadboard() {
    let mut shell = test_shell();
    shell.dispatch("add breadboard bb1").unwrap();
    assert_eq!(shell.project.components[0].r#type, "breadboard");
}

#[test]
fn shell_add_dupont() {
    let mut shell = test_shell();
    shell.dispatch("add dupont w1 color=red").unwrap();
    assert_eq!(shell.project.components[0].color.as_deref(), Some("red"));
}
```
