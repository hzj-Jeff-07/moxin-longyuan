0°-270° 映射到 ADC 值 0-1023，通过 D4-1 的 `set-adc` 通路注入。

### 3. RunState 加电位器状态

```rust
#[derive(Debug, Clone)]
pub struct PotentiometerState {
    pub angle_deg: f32,    // 0.0 - 270.0
    pub adc_value: u16,    // 派生：(angle / 270) * 1023
}

impl PotentiometerState {
    pub fn set_angle(&mut self, deg: f32) {
        self.angle_deg = deg.clamp(0.0, 270.0);
        self.adc_value = ((self.angle_deg / 270.0) * 1023.0).round() as u16;
    }

    pub fn nudge(&mut self, delta: f32) {
        self.set_angle(self.angle_deg + delta);
    }
}

pub struct RunState {
    // ...
    pub potentiometers: HashMap<String, PotentiometerState>,
    pub focused_potentiometer: Option<String>,   // TUI 当前选中
}
```

### 4. TUI 快捷键

在 src/tui.rs 命令模式按键处理里：

```rust
KeyCode::Char('[') => {
    if let Some(id) = state.lock().unwrap().focused_potentiometer.clone() {
        let delta = if key.modifiers.contains(KeyModifiers::SHIFT) { -1.0 } else { -10.0 };
        adjust_pot(&shell, &state, &id, delta);
    }
}
KeyCode::Char(']') => {
    // 同上，delta 正
}
```

`adjust_pot` 函数：

```rust
fn adjust_pot(shell: &mut Shell, state: &Arc<Mutex<RunState>>, id: &str, delta: f32) {
    let mut s = state.lock().unwrap();
    let pot = s.potentiometers.entry(id.into()).or_default();
    pot.nudge(delta);
    let adc = pot.adc_value;
    drop(s);   // 释放锁后写 stdin

    // 找到电位器 wiper 接的 board.A<n> 引脚
    let pin = find_pot_wiper_pin(&shell.project, id);   // 返回 "A0".."A5"
    if let (Some(sim), Some(pin)) = (shell.running.as_mut(), pin) {
        if let Some(stdin) = sim.stdin.as_mut() {
            let cmd = format!("set-adc {} {}\n", pin, adc);
            let _ = stdin.write_all(cmd.as_bytes());
        }
    }
}
```

### 5. focused_potentiometer 选择

如果项目里只有一个电位器，自动 focus。多个时按 `Tab` 切换 focus。

TUI 右侧 inspector 显示当前选中电位器和 angle / adc_value。

### 6. 渲染

电位器在 TUI components panel 里渲染为：

```
[Pot:pot1 ◐ 135.0° → 511]
```

旋钮符号根据角度选不同字符：`◐ ◑ ◒ ◓` 或简化的 `─`。

## 单元测试

```rust
#[test]
fn pot_angle_to_adc() {
    let mut p = PotentiometerState::default();
    p.set_angle(0.0);
    assert_eq!(p.adc_value, 0);
    p.set_angle(270.0);
    assert_eq!(p.adc_value, 1023);
    p.set_angle(135.0);
    assert!(p.adc_value > 500 && p.adc_value < 520);   // 511 +/- 取整误差
}

#[test]
fn pot_nudge_clamps() {
    let mut p = PotentiometerState::default();
    p.set_angle(0.0);
    p.nudge(-100.0);
    assert_eq!(p.angle_deg, 0.0);   // clamp 下限

    p.set_angle(270.0);
    p.nudge(100.0);
    assert_eq!(p.angle_deg, 270.0);  // clamp 上限
}
```
