## 任务

电位器调节 PWM duty cycle，LED 亮度跟随变化（在 TUI 里通过 PWM duty 数字体现）。

## 验收

```bash
cd examples/pot-led-brightness
moxin run
# TUI 进入后按 ] 几次 → PWM duty 数字变大（在 led panel 或 inspector 显示）
# 按 [ → duty 数字变小
```

注意：Phase 1 LED 只显示亮/灭，不显示亮度。所以验证点是 PWM duty 数值在变。

[project]
name = "pot-led-brightness"
board = "arduino-uno"
version = "0.2"

[[component]]

type = "potentiometer"

[[component]]

type = "led"
color = "red"

[[wire]]
from = "board.5V"

[[wire]]
from = "board.A0"
to = "pot1.wiper"
[[wire]]
from = "board.GND"
to = "pot1.terminal_b"
[[wire]]
from = "board.D9"        # D9 支持 PWM
to = "led1.anode"
[[wire]]
from = "board.GND"
to = "led1.cathode"
```

### src/main.ino

```cpp
void setup() {
    pinMode(9, OUTPUT);
    Serial.begin(9600);
}

void loop() {
    int adc = analogRead(A0);              // 0-1023
    int duty = map(adc, 0, 1023, 0, 255);  // 0-255 for PWM
    analogWrite(9, duty);
    Serial.print("ADC=");
    Serial.print(adc);
    Serial.print(" duty=");
    Serial.println(duty);
    delay(50);
}
```

### README.md

# pot-led-brightness example

Read potentiometer (A0), output PWM (D9) with proportional duty cycle.
Adjust the pot in TUI with `[` / `]` keys to see the duty value change
on serial console.

\```bash
moxin run
# Press ] / [ to rotate the potentiometer
\```

Phase 1 limitation: TUI shows LED as on/off only. Watch the Serial line
for PWM duty cycle (0-255) to confirm brightness modulation.
```
