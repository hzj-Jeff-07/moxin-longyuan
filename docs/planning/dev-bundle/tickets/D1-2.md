# D1-2 · 修 BridgeEvent::Button 的 _t_us 字段名拼错

预计工时：30 分钟
模块：sim

---

## 任务

`src/sim.rs` 中 `BridgeEvent::Button` 变体的字段名是 `_t_us`（带下划线前缀），但
bridge 协议发送的 JSON key 是 `t_us`（无下划线）。serde 反序列化此事件必然失败，
而 `reader_loop` 中 `if let Ok(ev) = ...` 静默吞掉了所有解析错误，导致 button 事件
永远更新不到 `RunState.button_pressed`。

## 现有代码

`src/sim.rs` 第 60-200 行的关键部分：

```rust
#[derive(Debug, Deserialize)]
#[serde(tag = "event")]
enum BridgeEvent {
    #[serde(rename = "ready")]
    Ready { mcu: String, freq: u32 },
    #[serde(rename = "pin")]
    Pin { t_us: u64, port: String, bit: u8, value: u8 },
    #[serde(rename = "serial")]
    Serial { t_us: u64, line: String },
    #[serde(rename = "exit")]
    Exit { state: i32 },
    #[serde(rename = "button")]
    Button { _t_us: u64, pressed: bool },   // ⚠️ 这里
}

fn apply_event(
    state: &Arc<Mutex<RunState>>,
    ev: BridgeEvent,
    is_d13: &dyn Fn(&str, u32) -> bool,
) {
    let Ok(mut s) = state.lock() else { return };
    match ev {
        // ...
        BridgeEvent::Button { pressed, .. } => {
            s.button_pressed = pressed;
            // ⚠️ 这里没更新 last_event_t_us
        }
    }
}
```

## 修改内容

1. **改字段名**：`BridgeEvent::Button { _t_us: u64, pressed: bool }`
   → `BridgeEvent::Button { t_us: u64, pressed: bool }`

2. **同步 apply_event**：Button 分支也更新 `s.last_event_t_us = t_us;`，
   与其他事件（Pin / Serial）保持一致。

3. **加测试**：在 `src/sim.rs` 底部的 `#[cfg(test)] mod tests` 里新增：

```rust
#[test]
fn apply_event_button_updates_state() {
    let state = Arc::new(Mutex::new(RunState::default()));
    let event_json = r#"{"event":"button","t_us":12345,"pressed":true}"#;
    let ev: BridgeEvent = serde_json::from_str(event_json)
        .expect("BridgeEvent::Button should deserialize from real bridge JSON");
    apply_event(&state, ev, &|_, _| false);
    let s = state.lock().unwrap();
    assert!(s.button_pressed);
    assert_eq!(s.last_event_t_us, 12345);
}

#[test]
fn apply_event_button_release() {
    let state = Arc::new(Mutex::new(RunState::default()));
    {
        let mut s = state.lock().unwrap();
        s.button_pressed = true;
    }
    let ev: BridgeEvent = serde_json::from_str(
        r#"{"event":"button","t_us":99999,"pressed":false}"#
    ).unwrap();
    apply_event(&state, ev, &|_, _| false);
    assert!(!state.lock().unwrap().button_pressed);
}
```
