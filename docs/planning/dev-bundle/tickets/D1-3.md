## 任务

README.md 现有"安装"章节教用户用 `alias moxin=...`，这种方式不会被脚本/Makefile/子 shell
继承，每次新终端都要重设。改用标准 Rust CLI 安装方式：`cargo install --path .` 把
二进制装到 `~/.cargo/bin`（默认在 PATH 里）。

## 验收命令

新机器从零安装：

```bash
git clone <repo> moxin-longyuan && cd moxin-longyuan
cargo install --path .
moxin --version    # 任意新终端能跑
moxin new demo --board=uno
cd demo
moxin run          # 跑通 blink
```

README 里的"安装"章节必须能引导用户走完上述流程。

## 修改内容

把"安装"章节改成：

```markdown
## 安装

需要 Rust 1.75+（rustup 安装：https://rustup.rs）

\```bash
# 一行装到 PATH
cargo install --path .

# 验证
moxin --version
\```

`cargo install` 会把 `moxin` 二进制装到 `~/.cargo/bin/`（rustup 默认已加入 PATH），
任何终端都能直接调用，无需 alias。

### Arduino 仿真依赖（可选）

如果要跑 Arduino Uno 后端，还需：

\```bash
# 编译 simavr bridge
cd bridge && make
cp moxin-simavr-bridge ~/.cargo/bin/

# 或：设置环境变量
export MOXIN_BRIDGE=$(pwd)/moxin-simavr-bridge
\```

并装 simavr 和 arduino-cli：

\```bash
# macOS
brew install simavr arduino-cli
# Ubuntu
sudo apt install simavr && curl -fsSL https://raw.githubusercontent.com/arduino/arduino-cli/master/install.sh | sh
\```

### STM32 仿真依赖（可选）

需要 QEMU + arm-none-eabi-gcc：

\```bash
# macOS
brew install qemu --cask gcc-arm-embedded
# Ubuntu
sudo apt install qemu-system-arm gcc-arm-none-eabi
\```
```
