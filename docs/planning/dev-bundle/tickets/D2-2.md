# D2-2 · TUI 输入条光标用 unicode-width 修 CJK / emoji 错位

预计工时：30 分钟
模块：tui

---

## 任务

`src/tui.rs` 第 414 行附近：

```rust
let cursor_x = outer[2].x + 8 + input.cursor as u16;
```

`input.cursor` 是 `Vec<char>` 索引，不是终端列宽。CJK 字符宽 2 列，emoji 通常也是 2，
组合字符 0。用户在 `moxin > ` 输入中文，光标位置就跟实际显示差几格。

## 验收命令

```bash
cd moxin-longyuan
cargo build --release
cd /tmp && moxin new test-uni --board=uno && cd test-uni
moxin run
```

TUI 里手动验证：
- 输入 `你好🎉test` 光标准确停在 t 后面（视觉上）
- 输入 `hello` 与现在一致（ASCII 不受影响）
- 按方向键移动光标，CJK 字符光标也正确
- backspace 一个 CJK 字符光标后退 2 列

## 加依赖

允许加 `unicode-width = "0.1"` 到 Cargo.toml `[dependencies]`。

## 实现

```rust
use unicode_width::UnicodeWidthStr;

// 现在
let cursor_x = outer[2].x + 8 + input.cursor as u16;

// 改成
let prefix: String = input.buffer[..input.cursor].iter().collect();
let cursor_x = outer[2].x + 8 + UnicodeWidthStr::width(prefix.as_str()) as u16;
```

如果 `input.buffer` 不是 `Vec<char>` 而是别的（先 view 一下 src/tui.rs 实际类型），
按实际类型取前 cursor 个字符的总列宽。

## 测试

```rust
#[cfg(test)]
mod cursor_width_tests {
    use unicode_width::UnicodeWidthStr;

    #[test]
    fn ascii_width_equals_char_count() {
        assert_eq!(UnicodeWidthStr::width("hello"), 5);
    }

    #[test]
    fn cjk_chars_are_two_columns_each() {
        assert_eq!(UnicodeWidthStr::width("你好"), 4);
    }

    #[test]
    fn mixed_ascii_cjk() {
        assert_eq!(UnicodeWidthStr::width("hi你好"), 6);
    }
}
```
