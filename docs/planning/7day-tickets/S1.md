# S1 · schema bundle 合并 + CI 校验脚本

## 任务

把 `moxin-schema-bundle/` 这一包合并进 moxin-longyuan 仓库，并加一个 CI 校验脚本：扫描 `components/*.toml` 和 `pin-anchors/*.json`，验证 `pins[].name` 两边严格一致、`electrical` 在 18 个枚举值内、JSON 格式合法。

这是阻塞建模部的串行任务，必须先做完才能开三个 worktree。

## 允许动的文件

- 新增 `docs/component-schema.md`
- 新增 `components/*.toml`（9 个）
- 新增 `pin-anchors-template/*.json`（9 个）
- 新增 `pin-anchors/`（空目录，给建模部填）
- 新增 `scripts/check_schema.py` 或 `scripts/check_schema.sh`
- 修改 `.github/workflows/ci.yml`（加 schema 校验 step）

## 验收

```powershell
cargo test
cargo clippy --all-targets
python scripts/check_schema.py     # 应输出: 9/9 components OK, 0 errors
```

CI 在缺一个引脚定义、多一个不在枚举里的 electrical 值、JSON 不合法这三种情况下必须 fail。

## 约束

- 不动 `src/` 任何文件
- 不动 `bridge/` 任何文件
- 校验脚本不许加重依赖，Python 用标准库 `tomllib` + `json`，Bash 用 `jq`
