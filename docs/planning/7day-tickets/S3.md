# S3 · STM32 wire PA13 统一 + examples 文件结构对齐

## 任务

1. **wire 一致性**：当前 `examples/stm32-blink/moxin.toml` 里 wire 指向的引脚名与 README 描述的不一致（PA13 vs D13）。以 STM32 真实引脚名 PA13 为准，统一 moxin.toml、README、code comment。
2. **examples 文件结构对齐**：现有 examples 各自结构不一（有的有 README，有的没有；有的 firmware/ 子目录，有的 src/ 子目录）。统一为：

```
examples/<name>/
├── README.md          ← 一句话说明 + 接线图 + 运行命令
├── moxin.toml         ← 项目配置
└── firmware/          ← 固件源码
    ├── platformio.ini 或 Cargo.toml
    └── src/main.* 或 src/main.rs
```

把现有 examples 全部对齐这个结构。

## 允许动的文件

- `examples/stm32-blink/**`（wire 修正 + 结构对齐）
- `examples/led-control/**`（结构对齐）
- 其它 `examples/*/`（如果有）
- `README.md` 里 examples 章节（如果引用了具体路径）

## 验收

```powershell
cargo test
cargo clippy --all-targets
# 所有 example 都能跑通
moxin run examples/stm32-blink
moxin run examples/led-control
# 检查每个目录都有 README.md
Get-ChildItem examples -Directory | ForEach-Object { Test-Path "$_/README.md" }
```

每个 example README 必须含：硬件清单、接线图 ASCII、运行命令、预期现象。

## 约束

- 不新建 example（C 窗口负责新建）
- 不动 firmware 代码逻辑，只动文件结构和命名
- moxin.toml 引脚名以 STM32 原生命名（PAx/PBx）为准
