# CLI 形态设计

## 面板布局

MoXin CLI 由四块面板组成：

```
┌─────────────────────────────────────────────────────┐
│  [Board] 板形 + 引脚连线                              │
├─────────────────────────────────────────────────────┤
│  [Serial Monitor] 程序输出流                          │
├─────────────────────────────────────────────────────┤
│  [AI Inspector] 状态 / 诊断                           │
├─────────────────────────────────────────────────────┤
│  moxin >                                             │
└─────────────────────────────────────────────────────┘
```

## 面板规格

### `[Board]` 板形 + 引脚连线

渲染当前板子的引脚布局与组件连线。格式：

```
PIN13 ●——[LED:led1 red ON #]
GND   ●——[Button:btn1 GND]
```

每行表达：哪个引脚连了什么组件、当前状态是什么。

接线通过命令驱动，不手填坐标：

```
wire pin13 -> led1.a
```

### `[Serial Monitor]` 程序输出流

实时滚动显示仿真程序 `Serial.print*` 的输出。

### `[AI Inspector]` 状态 / 诊断

把当前仿真器状态（电压、引脚电平、循环时间、按钮状态）结构化呈现。

**外接模型接口**：Inspector 通过 `Inspector` trait 抽象，支持接入外部 LLM API 或 MCP server 提供诊断建议。MoXin 不内置模型，只负责：
1. 提供结构化状态数据
2. 渲染外部模型返回的结果

未连接外部模型时，降级为纯状态展示。

### `moxin >` 输入条

始终固定在底部的命令输入入口，结果以 toast 形式反馈。
